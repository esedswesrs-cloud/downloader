⚙️ PENGATURAN

Instance resmi & komunitas memakai verifikasi anti-bot yang hanya jalan di situs resmi cobalt — jadi di web ini verifikasinya akan gagal (sudah saya tes). Solusi pasti: jalankan instance sendiri via Docker (±5 menit, tanpa verifikasi, YouTube ikut jalan) lalu isi URL http://localhost:9000/ di atas. File siap pakai: cobalt-docker-compose.yml
YouTube otomatis diambil via Piped (tanpa perlu instance) selama instance aktif tidak mendukung YouTube.
